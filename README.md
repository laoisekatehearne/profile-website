# Personal Profile Website

A simple personal profile website built with HTML and CSS. The site includes an About Me section, a skills list, a weekly schedule and a contact page.

## Technologies

- HTML
- CSS

## How to view the website

Download or clone this repository.

Open the project folder and double-click:

`index.html`

The website will open in your default web browser.

You do not need to install any dependencies or run a server.

To view the contact page, click **Contact** in the navigation bar or open:

`contact.html`

## Project structure

- `index.html` — main profile page.
- `contact.html` — contact form page.
- `styles.css` — website styling.
- `dog.jpg` — image used on the profile page.
- `screenshot.jpg` — screenshot of the finished website.
